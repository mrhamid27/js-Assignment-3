## 📝 Practice Questions

### Q1 — Merge Two Arrays

### Q2 — Count Occurrences

Find how many times a specific number appears in an array.

### Q3 — Sum of Even Numbers

Calculate the sum of only the even numbers in an array.

### Q4 — Separate Positive and Negative Numbers

Create two new arrays containing positive and negative numbers separately.

### Q5 — Check Sorted Array

Check whether an array is sorted in ascending order.

### Q6 — Count A Grade Students

Calculate grades for students and count how many students received an A Grade.

### Q7 — Remove Duplicates and Calculate Sum

Remove duplicate values from an array using `includes()` and calculate the sum of the unique values.

### Q8 — Total Bill and Discount

### Q9 — Average and Above-Average Numbers

Calculate the average of an array and count how many numbers are greater than the average.

## 🧠 Key Concepts Practiced

### For Loop

```js
for (var i = 0; i < array.length; i++) {
    // code
}
```

Used to traverse and process every element of an array.

### Counting

```js
var count = 0;

if (condition) {
    count++;
}
```

Used to count elements that meet a specific condition.

### Sum

```js
var sum = 0;

sum += numbers[i];
```

Used to calculate the total of array values.

### Push

```js
array.push(value);
```

Used to add a value to the end of an array.

### Includes

```js
array.includes(value);
```

Used to check whether a value already exists in an array.
